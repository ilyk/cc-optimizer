## 💾 **Data & Caching**

### Multi-Layer Architecture
**Android (Room)**:
- Credit cards: 24h cache
- Recommendations: 1h cache
- Overrides: Permanent

**Backend (In-Memory)**:
- Statement analysis: 30-day cache
- Auto-cleanup every hour

### Cache Strategy
1. Try cache (instant)
2. API if needed
3. Update cache
4. Fall back to stale cache on error

**Result**: **Works offline + 100x faster!**
